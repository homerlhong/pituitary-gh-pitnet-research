# Pituitary Tumor Prediction

一个用于研究垂体瘤术后复发或进展风险的**研究原型**。

当前优先研究对象是**海绵窦侵袭性 GH 分泌型 PitNET**。项目将从静态的预后预测，推进为以术后 3 个月为决策点的动态治疗策略研究：在继续药物、早期立体定向放射外科（SRS／伽马刀）和再次手术之间，评估患者的长期净临床获益。

## 第一版目标

在首次手术后，基于术前与围手术期资料估计患者在 3 年内发生影像学进展或需要再治疗的风险。

该项目的第一阶段只使用**模拟数据**验证分析工作流。它不是医疗器械，不能用于患者诊断、治疗或随访决策。

## 研究问题

> 对接受首次手术的垂体瘤患者，年龄、肿瘤大小、影像侵袭、细胞谱系、术后残留和早期激素反应等信息，能否预测 3 年内的进展或再治疗？

## 项目结构

```text
data_contract/       变量和结局定义
docs/                研究方案与安全边界
src/                 模拟数据与基线模型代码
tests/               最小测试
```

## 快速开始

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
python -m src.train_baseline
```

运行后会在 `artifacts/` 生成一个模拟训练报告。真实数据只能在获得伦理审批、数据使用授权和充分去标识化后接入；不得提交至本仓库。

## 成功标准

第一版的成功不是高分，而是：结局定义明确、流程可复现、结果可审计、并为后续外部验证做好准备。

## 动态治疗策略子研究

详见 [研究方案](studies/01-gh-pitnet-cavernous-sinus/10-dynamic-treatment-decision-protocol.md)。该子研究不把「是否接受伽马刀」误当作普通预测变量；它把治疗选择视为时间依赖暴露，并预设处理适应证偏倚、治疗等待期偏倚和随访不均衡。
