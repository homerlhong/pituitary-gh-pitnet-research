# 04｜数据与证据基础

## 最小多模态数据集
- 临床：诊断时间、症状、共病、关键结局与随访。
- 内分泌：激素、检测方法、单位、采样日期。
- 影像：检查日期、肿瘤大小或体积、侵袭与术后残留。
- 病理：细胞谱系、免疫组化、增殖相关指标。
- 治疗：手术、药物剂量与时长、放疗、再治疗。
- 分子：仅在研究问题和样本质量支持时扩展。

## 质量闸门
1. 每个变量有定义、单位、允许范围和时间锚点。
2. 每个结局有判定依据和裁决流程。
3. 描述缺失、失访和不同检测方法，不用静默填补掩盖问题。
4. 训练、验证与外部测试数据严格隔离。

## 产出
数据字典、数据血缘图、质量报告、可复现提取脚本。
