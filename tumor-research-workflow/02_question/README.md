# 02｜选择第一个可赢的问题

## 选择标准
优先选择同时满足以下条件的问题：
- 对患者结局有实质影响；
- 结局可定义、可追踪；
- 数据或样本有现实获取路径；
- 结果可被独立验证；
- 结论有潜在行动价值。

## 研究问题卡模板
- **人群：** 谁？
- **时间点：** 在何时做判断？
- **预测或解释对象：** 什么特征？
- **结局：** 发生什么、如何判定？
- **比较：** 与现行做法相比什么？
- **行动：** 如果结果成立，会改变什么？
- **验证：** 用哪一个独立数据源确认？

## 垂体瘤优先问题示例
能否在首次治疗前或早期，识别未来更可能出现影像进展、复发或标准药物治疗反应不足的患者？
