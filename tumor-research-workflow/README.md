# 肿瘤研究工作流

这套工作流把“攻破肿瘤”的长期愿景，转化为可重复、可审计、可验证的研究循环。

```text
使命 → 全景判断 → 问题选择 → 合规与协作 → 数据基础
→ 发现 → 验证 → 转化 → 学习与迭代
```

垂体瘤是第一个研究场景，不是方法的边界。每一个阶段必须产出可被下一阶段使用和检验的成果。

| 节点 | 核心问题 | 最小产出 |
| --- | --- | --- |
| 00 使命 | 我们要改变什么？ | 北极星与边界 |
| 01 全景 | 现有证据和空白在哪里？ | 问题地图 |
| 02 问题 | 哪个问题最值得先做？ | 研究问题卡 |
| 03 治理 | 能否合法、安全、透明地做？ | 方案与审批记录 |
| 04 数据 | 用什么证据回答？ | 数据字典与质量报告 |
| 05 发现 | 看到了什么规律？ | 可复现探索结果 |
| 06 验证 | 规律是否可靠？ | 独立验证报告 |
| 07 转化 | 如何改善决策或治疗？ | 临床/实验转化计划 |
| 08 运营 | 如何持续学习？ | 版本、决策与复盘 |

**原则：** 不把探索性相关性当作临床结论；不公开患者可识别信息；任何面向患者的建议均须经过独立验证和专业临床审核。
