# 研究 01：治疗路径定义与时间零点

## 目的

对海绵窦侵袭生长激素瘤，术后治疗并不是一次性的选择，而是一条会随残留、激素控制、视功能和患者偏好变化的路径。本文件定义观察性研究中如何编码这些路径，避免时间偏倚。

## 共同起点与评估窗口

- **共同零时点：** 首次经蝶手术日期。
- **基线风险窗口：** 术前至首次术后 MRI，以及预设早期生化评估。
- **路径分配窗口：** 术后 0–6 个月；该窗口只用于描述初始策略，不把尚未发生的未来治疗提前当作基线信息。
- **长期随访：** 从手术日起，直至事件、末次随访、死亡或预设截点。

早期 IGF-1 的解释应记录检测日期；术后轻度异常可能需要在 3–6 个月复测后才能稳定判定，因此不能用单一过早检验值武断定义失败。

## 四条主要路径

| 路径 | 操作性定义 | 关键日期 | 不能被误算为 |
| --- | --- | --- | --- |
| A：术后药物/观察路径 | 初次手术后，以观察和/或药物控制为主，尚未实施再次手术或 SRS/GK | 药物开始、调整、停用；每次 MRI 与 IGF-1/GH | “不治疗”；必须区分主动观察与药物治疗 |
| B：早期 SRS/GK 路径 | 在术后预设早期窗口内，针对可见残留或持续激素活动安排 SRS/GK | 决策日、计划日、照射日、靶区/剂量 | 把计划日当作真正暴露日；暴露以实际照射日为准 |
| C：延迟 SRS/GK 路径 | 初始药物/观察后，因持续控制不足、进展或其他预设指征接受 SRS/GK | 触发原因、决定日、照射日 | “自然更差”；其接受 SRS 前的随访时间必须正确计入 |
| D：再次手术路径 | 初次手术后因可达残留、压迫症状、进展或预设临床原因再次手术 | 决策日、再次手术日、术后影像 | 与 SRS/GK 随意合并；二者适用解剖条件不同 |

患者可从一条路径转换至另一条。真实世界研究不应强迫每位患者只属于一条固定组。

## 路径转换规则

每次转换均需要完整记录：

1. 转换日期；
2. 触发原因：生化持续活动、影像进展、残留位置/体积、视功能、药物不耐受、患者偏好或其他；
3. 之前累计治疗与反应；
4. 转换后的实际治疗日期和技术细节。

### 常见序列

```text
手术 → 观察/药物 → SRS/GK
手术 → 早期 SRS/GK → 长期生化与内分泌随访
手术 → 再手术 → 药物或 SRS/GK
手术 → 药物 → 再手术 → SRS/GK
```

## SRS/GK 专属变量

若接受伽马刀或其他立体定向放射外科/放疗，需记录：

- 设备与技术类别：GK、LINAC SRS、分割立体定向放疗等；
- 实际照射日期；
- 靶区体积、边缘剂量、分割方案与等剂量线；
- 与视交叉、视神经、颈内动脉和海绵窦颅神经的空间关系；
- 术前/术后用药状态；
- 影像控制、生化控制的评估日期；
- 新发垂体功能减退、视/颅神经事件及其日期。

公开证据支持 SRS 在经手术后持续或复发性疾病中作为一种选择，但反应通常具有时间滞后，且需长期监测垂体功能与视觉/神经系统安全性。因此它的疗效和损伤都必须做时间到事件分析，而不是只比较末次随访状态。

## 主要比较的三个层次

### 层次 1：描述性路径图

展示患者从手术到药物、再次手术或 SRS/GK 的真实序列；不作因果结论。

### 层次 2：临床可比人群中的策略比较

在具有相似残留位置/体积、早期 GH/IGF-1、Knosp 程度、视功能和病理特征的患者中，比较不同策略下的结局。必须处理治疗选择偏倚。

### 层次 3：动态策略与个体化预测

在每个随访节点更新风险：继续药物、再次手术或 SRS/GK 在当前状态下可能带来的肿瘤控制与功能风险。该层次只在前两层结果稳定后开展。

## 分析设计警报

- **不死时间偏倚：** 把后来才接受 SRS/GK 的患者从手术当天算入 SRS 组，会让该组凭空获得“等待治疗期间未发生事件”的时间。
- **适应证混杂：** 残留更大、海绵窦更深或生化更难控制的患者更可能接受 SRS/GK；未经调整的组间差异不能解释为治疗效果。
- **时间依赖混杂：** GH/IGF-1、残留体积和药物剂量随时间变化，并同时影响后续治疗选择与结局。
- **竞争风险：** 新发垂体功能减退、死亡、失访或其他治疗可能改变对主要结局的观察。

## 推荐分析方案（按成熟度）

1. 多状态模型：描述治疗路径与状态转换。
2. 时间依赖 Cox 或 landmark 分析：作为基础比较。
3. 目标试验模拟：预先写明纳入、宽限期、策略、随访、结局和分析计划。
4. 边际结构模型或 g 方法：仅在样本量、变量完整度和统计支持足够时处理时间依赖混杂。

## 现在不做的事

- 不把任何路径写成对所有患者都适用的临床推荐。
- 不把“曾接受 SRS/GK”作为静态基线变量。
- 不把不同设备、不同剂量和不同适应证的放疗静默合并。
- 不只报告肿瘤缩小而忽略新发垂体功能减退和视觉/颅神经风险。
