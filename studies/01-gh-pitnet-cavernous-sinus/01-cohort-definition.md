# 研究 01：海绵窦侵袭生长激素瘤的多模式治疗路径

## 当前步骤：定义目标人群

## 研究问题

对存在海绵窦侵袭的成人生长激素瘤患者，在首次经蝶手术后，不同的“药物治疗、再次手术和立体定向放疗/伽马刀”路径与长期生化控制、肿瘤控制和治疗相关损伤有何关联？

本项目首先是观察性比较有效性研究与预测研究的基础，不为个体患者制定治疗方案。

## 目标试验式定义

| 项目 | 初步定义 |
| --- | --- |
| 目标人群 | 成人、明确 GH 分泌 PitNET/肢端肥大症、首次手术前存在海绵窦侵袭证据的患者 |
| 零时点 | 首次经蝶手术日期 |
| 共同基线 | 手术前临床/内分泌/MRI；以及首次术后 MRI 和预设早期生化评估 |
| 暴露路径 | 药物为主、早期 SRS/GK、延迟 SRS/GK、再次手术等；按实际发生日期编码 |
| 主要结局 | 3 年影像进展或因控制不足的再治疗 |
| 关键次要结局 | 生化控制、残留肿瘤控制、新发垂体功能减退、视/颅神经结局和总治疗负担 |

## 纳入标准

1. 手术时年龄 ≥18 岁。
2. 临床、生化及影像符合 GH 分泌 PitNET/肢端肥大症；保存诊断依据和检测方法。
3. 接受首次针对该肿瘤的经蝶手术。
4. 术前 MRI、手术记录或影像复核中存在海绵窦侵袭证据。
5. 至少具备：术前 MRI、手术日期、首次术后 MRI 或早期内分泌评估中的一项；缺失情况必须可追溯。

## 海绵窦侵袭的操作性定义

将每位患者的海绵窦侵袭证据拆开保存，不只记录一个“是/否”标签：

- `knosp_grade`：原始 Knosp 分级及阅片来源。
- `radiology_invasion_flag`：基于预先规定 MRI 规则的侵袭判定。
- `operative_cavernous_sinus_involvement`：术中记录的受累情况。
- `reviewer_id` 与 `review_date`：若做中央影像复核。
- `invasion_confidence`：明确 / 可能 / 不确定。

主要分析使用预先指定的影像标准；敏感性分析可分别使用影像、术中和联合定义，检验定义变化是否改变结论。

## 排除或单独建队列的情况

| 情况 | 处理原因 |
| --- | --- |
| 儿童/青少年或巨人症 | 遗传背景、自然史与治疗路径不同 |
| 既往接受同一肿瘤手术、放疗或系统性治疗 | 无法定义“首次手术”治疗起点 |
| 垂体癌或存在远处转移 | 疾病生物学与治疗强度不同，应单列 |
| 非 GH 分泌的 PitNET | 生化目标、药物和结局不同 |
| 无法确认肿瘤类型或手术日期 | 不能建立可靠零时点 |

## 不能直接排除、但必须标记的情况

- 混合 GH/PRL 分泌或多激素表达。
- 遗传综合征或早发病例。
- 多次分期手术。
- 妊娠相关诊疗阶段。
- 术后残留很小但生化持续活动。
- 影像与术中侵袭判断不一致。

这些患者应保留，并在预先规定的亚组或敏感性分析中处理；不能因为结果不方便而事后删除。

## 分层变量（进入比较前必须确定）

1. Knosp 分级或等价侵袭严重度。
2. 术后残留大小与位置。
3. 早期 IGF-1/GH 状态及检测时间。
4. 肿瘤颗粒化/病理亚型及药物相关标志物（如可得）。
5. 视路受压、视功能及颅神经状态。
6. 初始手术年代与中心/术者编码。

## 当前不做的事

- 不把所有 GH 瘤、所有垂体瘤和所有放疗病例合并。
- 不用治疗后才出现的数据定义基线风险。
- 不把是否接受伽马刀当作随机分配；治疗选择本身受残留、激素水平、患者偏好与中心实践影响。
- 不据此文档对单个患者作出治疗建议。

## 下一步

定义四类治疗路径的准确起点、宽限期和转换规则，避免把“接受治疗前必须存活”的时间错误归因给某一种治疗。
