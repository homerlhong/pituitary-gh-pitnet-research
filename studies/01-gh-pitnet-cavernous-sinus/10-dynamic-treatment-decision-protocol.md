# GH-PitNET 海绵窦侵袭：术后动态治疗决策研究方案 v0.1

> 研究用途：方案开发和分析预演。不能用于任何个体患者的临床治疗决策。

## 1. 临床问题

对首次经蝶手术后仍有残余瘤和/或持续 GH-IGF-1 生化活动的海绵窦侵袭性 GH 分泌型 PitNET 患者，在术后 3 个月这个可重复判定的节点，何种后续策略带来最佳 5 年净临床获益？

候选策略：

1. **继续或启动药物治疗**：以生长抑素受体配体为主，按临床实际记录联合/转换方案；
2. **早期 SRS（含伽马刀）**：在 landmark 后预设窗口内实施；
3. **再次手术**：仅在 MDT 认为残余位置、视路风险或减瘤目标支持时实施。

本研究不预设任何策略必然优于另一策略。

## 2. 为什么选择术后 3 个月作为 landmark

- 该时间点通常可获得可解释的术后 MRI、IGF-1、GH/OGTT 和垂体功能结果；
- 避免把立即术后影像改变或尚未稳定的激素值当作残余/失败；
- 使所有入组者均已存活且未在 landmark 前发生定义的主要结局，从而减少不死时间偏倚。

真实研究可将 90 天设为主分析，并以 12–16 周窗口和 6 个月窗口进行敏感性分析。

## 3. 目标试验（target trial）框架

| 元素 | 预设内容 |
|---|---|
| 资格 | 成年、首次手术、术前影像确认海绵窦侵犯、术后 3 个月有 MRI 与生化评估、未发生紧急再干预 |
| 时间零点 | 术后第 90 天；所有协变量仅使用该日前可获得的信息 |
| 分配策略 | 药物优先、早期 SRS、再次手术；记录实际 MDT 决策与患者偏好 |
| 宽限期 | 预先注册早期 SRS/再手术的实施窗口；窗口外治疗按方案偏离处理 |
| 随访 | 从 landmark 至 5 年、死亡、失访或行政截止 |
| 混杂控制 | 倾向评分、逆概率加权、克隆-删失-加权，以及关键未测量混杂的敏感性分析 |

## 4. 分层变量

### 术前与手术期

- 年龄、性别、诊断至手术时间、合并症和基线垂体功能；
- Knosp、侧别、海绵窦内侧壁侵犯、视路距离、最大径/体积和 T2 信号；
- 术式、术者/中心、术中海绵窦处理、切除程度与围术期并发症。

### 术后 3 个月 landmark 状态

- 残余瘤位置、体积、与视神经/颈内动脉距离；
- IGF-1（必须保留检测方法、年龄/性别校正和 ULN 倍数）；
- 随机 GH、OGTT GH nadir（如可用）、症状与并发症；
- 新发或持续性垂体功能减退；
- 病理谱系、颗粒化模式、Ki-67、SSTR2；分子资料仅作为增量模块，不能替代临床和影像模型。

## 5. 结局：5 年净临床获益

主分析先报告各组成终点，再报告一个预注册的患者层面复合结局，避免单一生化终点主导结论。

| 组成 | 建议定义 |
|---|---|
| 生化控制 | 年龄校正 IGF-1 正常；并保留 GH/OGTT 和检测平台 |
| 局部肿瘤控制 | 无经中心影像复核确认的进行性生长，且无因进行性肿瘤而紧急再局部治疗 |
| 治疗损害 | 新发永久性垂体功能减退、放射性视路损害、严重药物代谢毒性或重大再手术并发症 |
| 患者层面 | 症状、并发症控制、治疗负担和可获得的 PRO/QoL |

净获益的权重不能由模型开发者自行设定：应由多学科临床团队和患者代表共同定义，并对不同权重进行敏感性分析。

## 6. 分析顺序

1. **描述性队列**：评价 landmark 时不同策略组的可比性及缺失模式；
2. **预后模型**：预测 1、3、5 年的持续生化活动、影像进展和新发垂体功能减退；
3. **因果策略比较**：以目标试验模拟估计各策略的绝对风险、风险差、限制平均无事件时间和净获益；
4. **异质性治疗效应**：仅在样本量、事件数和重叠性充足时，探索哪些患者有策略差异；
5. **验证与审计**：按时间、术者/中心和检测平台验证；报告校准、重叠、权重稳定性、E-value/定量偏倚分析。

## 7. 不能做的推断

- 不能将接受 SRS 的患者与未接受者的原始结局差异解释为 SRS 效果；
- 不能把 landmark 之后的激素、影像或治疗信息放入 landmark 预测器；
- 缺乏外部验证前，不能生成个体化治疗推荐或部署为临床工具；
- 观察性研究只能提供条件性策略证据，不替代随机试验。

## 8. 最小数据可用门槛

在启动真实分析前，至少确认：

- 每例患者有可链接的手术日期、术后 MRI 日期、IGF-1 日期和治疗日期；
- 能区分残余稳定、影像进展、药物控制不足和患者偏好导致的治疗变更；
- 放疗资料含日期、技术、边缘剂量、靶区、视路剂量（如可得）；
- 随访可确定垂体功能轴和治疗相关毒性；
- 已获得 IRB/伦理、数据使用审批和去标识化治理。
