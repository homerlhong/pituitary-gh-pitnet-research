# 研究 01 数据可用性报告（模板）

> 使用 `python -m src.report_research01_data_quality` 自动生成。此模板说明报告应回答的问题；不要在公开仓库提交含真实患者信息的报告。

## 发布前核对

- [ ] 已运行结构与时间顺序质控。
- [ ] 已报告每张表的记录数、患者覆盖和日期范围。
- [ ] 已报告关键 MRI、内分泌、放疗和结局字段的可用率。
- [ ] 已检查不同治疗路径的随访是否系统性不同。
- [ ] 已检查数据中没有直接或间接可识别信息。

## 建模门槛（初步）

只有当主要结局定义、关键预测变量、治疗日期和随访时间可追溯时，才进入建模。具体事件数与模型复杂度由统计团队根据真实数据决定，不能用固定样本量口号替代评估。
