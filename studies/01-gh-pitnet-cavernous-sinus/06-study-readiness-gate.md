# 研究 01 启动建模前的准备度闸门

## 目的

本清单用于决定真实数据是否可以从“数据接入与描述”进入“预测建模”或“治疗策略比较”。它不是伦理审批替代品，也不设定机械的通过率；每项判断必须留下依据与日期。

## 闸门 A：治理与安全

- [ ] 已确认伦理审批、豁免或数据使用授权的适用范围。
- [ ] 已明确数据控制者、访问人员、分析环境和导出规则。
- [ ] 真实患者数据、影像和遗传数据不进入公开 GitHub 仓库。
- [ ] 研究 ID、日期处理和可识别信息的去标识化规则已经书面化。
- [ ] 研究问题、主要结局和分析计划已有版本号与冻结日期。

**未满足时：** 停止数据导出和建模，只完成方案与安全准备。

## 闸门 B：队列与时间轴

- [ ] 每名主队列患者都有可核验的首次手术日期。
- [ ] 海绵窦侵袭证据可追溯到 MRI、术中记录或预设中央复核。
- [ ] 术后首次 MRI 与早期 IGF-1/GH 的实际日期可获得。
- [ ] 每次药物、SRS/GK、再次手术都有实际发生日期。
- [ ] 每位患者有末次无事件随访、事件日期或明确失访原因。

**未满足时：** 只能做数据整理和描述，不能训练时间到事件模型或比较策略。

## 闸门 C：结局裁决

- [ ] 稳定残留、影像进展、复发和再治疗已按预设规则区分。
- [ ] 每个主要结局候选事件都有证据来源与裁决状态。
- [ ] 再治疗的临床指征已结构化，而非只记录“做过治疗”。
- [ ] 视功能、垂体功能减退与其他安全事件有基线状态和发生日期。

**未满足时：** 不得把未经裁决的自由文本或单次影像印象作为模型标签。

## 闸门 D：预测模型准备度

- [ ] 主要结局事件数与候选参数数量相称；复杂度由事件数而不是算法热度决定。
- [ ] 预测时间点之前的变量已与未来信息明确隔离。
- [ ] 缺失模式、缺失原因与不同路径/中心/年代的关系已报告。
- [ ] 至少有时间外验证或合理的内部验证设计；外部验证路径已规划。
- [ ] 模型评估计划包含校准度、区分度、临床阈值下获益与失败案例。

**通过后：** 可以运行研究型基线预测模型；结果仍不可用于临床决策。

## 闸门 E：策略比较准备度

- [ ] landmark 日、宽限期和两种策略的实际暴露日期已冻结。
- [ ] 两组均有足够患者与结局，且不存在明显的完全不可比性。
- [ ] 残留体积、Knosp、早期生化活动、视觉通路关系、病理和中心/年代等关键混杂因素可用。
- [ ] 已生成未调整协变量平衡报告；必要时制定加权/匹配后的平衡诊断计划。
- [ ] 不死时间偏倚、交叉治疗、竞争风险和失访处理已在方案中明确。

**通过后：** 才可进行调整后的关联分析或目标试验模拟；报告仍须使用谨慎的观察性语言。
