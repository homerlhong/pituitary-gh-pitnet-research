# 垂体瘤研究结局定义框架（v0.1）

## 为什么先定义结局

垂体瘤的“复发”“残留”“进展”“耐药”常被混用。它们不是同一件事；若混为一个标签，任何模型都会学到不一致的结果。本文件定义研究用结局，真实项目仍需由临床、影像、病理和统计团队共同确认。

## 结局层级

```text
肿瘤控制：影像学变化 / 生化变化
临床影响：视功能、垂体功能、症状、生活质量
治疗轨迹：药物反应、再手术、放疗、系统治疗
最终事件：进展、复发、耐药、转移、死亡
```

## 主要结局：3 年进展或因控制不足的再治疗

### 变量名

`progression_or_retreatment_3y`

### 起点

首次针对该 PitNET 的手术日期。对主要接受药物治疗的亚型，应另建“药物治疗起点”队列，不与术后队列混合。

### 事件满足以下任一项

1. **影像学进展**：在具有可比性的连续 MRI 上，由预设规则判定的肿瘤增大或新发解剖受累；必须保存两次 MRI 日期、测量方法与原始判读。
2. **因肿瘤控制不足的再治疗**：再手术、放疗、或新增系统性抗肿瘤治疗；必须记录治疗日期及临床指征。

### 不算事件

- 术后已有残留但在随访中稳定。
- 仅因常规计划或非肿瘤控制原因调整治疗。
- 没有可追溯影像、病历或治疗记录支持的“疑似复发”。

### 删失

末次确认无事件随访日；死亡、失访或转出需要单独编码原因。若研究中死亡与肿瘤过程相关，应考虑竞争风险分析。

## 次要结局

| 结局 | 定义要点 | 适合的分析 |
| --- | --- | --- |
| 影像学进展时间 | 仅使用经过影像规则确认的进展 | 生存分析、纵向体积模型 |
| 生化控制 | 按亚型预先定义的激素目标；记录检测平台和用药状态 | 纵向混合模型、动态预测 |
| 药物反应不足/耐药 | 药物、剂量、最短疗程、依从性和反应阈值全部预设 | 亚型内队列分析 |
| 视功能恶化 | 预设视力/视野检查的临床意义阈值 | 重复测量和时间到事件分析 |
| 新发垂体功能减退 | 指定激素轴及替代治疗开始日期 | 竞争风险/多状态模型 |
| 再手术 | 记录指征、日期、术式和术后结局 | 因果与治疗路径分析 |
| 治疗负担/生活质量 | 使用同一量表及版本，保存时间点 | 纵向患者报告结局分析 |

## 侵袭性、复发与耐药：必须分开

| 概念 | 研究定义 | 不能替代什么 |
| --- | --- | --- |
| 侵袭性 | 影像、术中或病理证据提示局部侵入周边结构 | 不是复发或耐药的同义词 |
| 术后残留 | 首次术后 MRI 可见的肿瘤组织 | 不等同进展 |
| 进展 | 预设随访期内的客观增长或新发受累 | 不等同任意再治疗 |
| 复发 | 完全切除/缓解后再次出现可确认病变或疾病活动 | 不等同残留生长 |
| 耐药 | 在标准、足量、足疗程且依从性可接受的治疗下，未达到预设反应 | 不能仅凭“仍有残留”判断 |
| 侵袭性 PitNET | 临床上出现异常快速增长或经标准治疗后有临床相关进展的综合表型 | 不能由单一 Ki-67 或基因结果诊断 |

2025 ESE 指南将侵袭性 PitNET 视为基于侵袭、异常快速生长或标准治疗后临床相关进展的临床综合表型；因此模型应保留构成这一表型的原始证据，而不是只保存一个二元标签。

## 结局裁决表：每个候选事件必须记录

| 字段 | 说明 |
| --- | --- |
| `patient_id` | 去标识化研究 ID |
| `event_candidate_date` | 首次出现疑似事件的日期 |
| `event_type` | 影像进展 / 生化失控 / 再治疗 / 其他 |
| `evidence_source` | MRI、实验室、病历、手术或放疗记录 |
| `baseline_comparator_date` | 与哪一次基线或前次检查比较 |
| `adjudication_status` | 已确认 / 未确认 / 信息不足 |
| `adjudicator_role` | 影像、内分泌、神经外科或联合裁决 |
| `adjudication_date` | 裁决日期 |
| `notes` | 不确定性与例外情况 |

## 分析前检查清单

1. 每位患者是否有明确零时点？
2. 主要结局是否不依赖预测时点之后才知道的信息？
3. 是否把残留稳定误算为复发？
4. 是否记录了不同治疗开始时间，避免不死时间偏倚？
5. 是否有足够随访，且失访模式已描述？
6. 是否按病理谱系和功能亚型分层，而非盲目合并？

## 第一版推荐

先使用“术后 3 年进展或因控制不足的再治疗”作为主要结局；把影像进展、生化控制、药物反应不足、视功能和生活质量作为独立次要结局。这样既保持可执行性，也不会丢失临床复杂性。
