# 研究方案 v0.1

## 模型用途

研究性预后预测：估计首次手术后 3 年内影像学进展或再治疗的风险。

## 目标人群

首次接受垂体瘤手术、具有基线影像和至少一次术后评估记录的成年患者。真实研究需预先确定具体亚型、入排标准和数据来源。

## 主要结局

从手术日起 3 年内的复合结局：

1. 经预先规定标准确认的影像学进展；或
2. 因肿瘤控制不足而进行再手术、放疗或新增系统性肿瘤治疗。

真实研究必须区分“术后残留稳定”与“真正进展”，并保留每一事件的判定证据。

## 预设预测变量

- 年龄
- 术前最大径
- MRI 侵袭特征
- 功能性亚型/细胞谱系
- 术后残留
- 早期生化反应

变量必须在预测时间点可获得。不可将未来随访、再治疗或结局信息泄漏进模型。

## 验证计划

第一阶段使用交叉验证检查可复现性；随后进行时间外验证和独立中心外部验证。报告校准度、区分度、置信区间与临床阈值下的净获益，而不仅是准确率。

## 安全说明

本项目仅供研究和教育。任何真实数据接入、临床评估或临床部署均需伦理批准、数据治理和独立临床审核。
