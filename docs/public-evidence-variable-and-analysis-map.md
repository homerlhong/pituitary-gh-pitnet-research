# 垂体瘤公开证据：变量与分析地图（2026-11）

## 范围与使用方式

本文基于公开可获得的近年 WHO 分类、国际共识、2025 ESE 指南和多组学综述，整理垂体神经内分泌肿瘤（PitNET）研究所需变量与分析路径。它不是系统综述或临床指南，不能替代个体化诊疗。

核心原则：**按证据成熟度分层，不把探索性生物标志物直接放入临床预测模型。**

## 三层变量架构

| 层级 | 作用 | 能否进入第一版临床预测模型 |
| --- | --- | --- |
| A：临床成熟 | 已进入常规诊疗或有较稳定定义 | 可以，优先使用 |
| B：增强/转化 | 有合理证据，需标准化和外部验证 | 仅做增益评估 |
| C：发现/机制 | 多组学、空间与新型生物标志物 | 不进入临床模型；用于分型和机制发现 |

## A 层：临床成熟变量

### 1. 患者与遗传背景

- 年龄、性别、诊断及手术日期、家族史、既往肿瘤/内分泌疾病。
- 遗传易感线索：年轻起病、家族聚集、多发内分泌肿瘤表现等。
- 儿童/青少年、妊娠和遗传性病例应单列分析，不能简单混入成人队列。

### 2. 临床与内分泌

- 功能性状态与综合征：PRL、GH/IGF-1、ACTH/皮质醇、TSH 等相关表型。
- 每次激素检测的：日期、项目、数值、单位、参考区间、检测平台和同期用药。
- 垂体各轴功能、激素替代治疗、视力/视野、头痛与其他神经症状。
- 药物暴露：名称、剂量、开始/停止日期、依从性线索、不良事件和反应。

### 3. MRI 与解剖

- MRI 日期、扫描协议、磁场强度、层厚、对比剂。
- 三轴径和/或体积；鞍上、鞍旁、海绵窦侵袭；颈内动脉、视交叉、垂体柄及正常腺体关系。
- 术前、首次术后、每次随访影像均保留日期和结构化评估。
- 侵袭、增长和残留必须分开编码；残留稳定不等同复发。

### 4. 手术、病理与治疗

- 手术入路、日期、初次/再手术、切除程度、术中残留原因、并发症。
- 病理：激素免疫组化、转录因子谱系（PIT1、TPIT、SF1）、细胞角蛋白/颗粒化模式、Ki-67、核分裂计数、p53 染色。
- 放疗：类型、剂量、靶区和日期；再手术与系统治疗也必须有明确指征。

2025 ESE 指南明确强调侵袭性病例应进行标准化影像和病理报告，并讨论分子分析；侵袭性本身仍主要是一个临床复合概念，而非单一病理阈值。 [ESE 2025 指南](https://www.ese-hormones.org/news/out-now-revised-ese-clinical-practice-guideline-for-the-management-of-aggressive-pituitary-tumours-and-pituitary-carcinomas/)

## B 层：增强与转化变量

### 1. 影像组学与纵向影像

- 经固定、可复现的分割流程提取形状、纹理、强化与周边结构特征。
- 原始影像和 ROI、分割者、软件版本、特征提取版本必须可追溯。
- 分析重点：与基础 MRI 指标相比，影像组学是否在时间外/外部队列提供增益。

### 2. 高风险病理与蛋白标志物

- 在统一实验与阅片条件下，可探索 PTTG、DNA 修复相关蛋白、细胞周期、侵袭/基质重塑、免疫相关标记等。
- 记录抗体、平台、评分方法、切片批次、阳性细胞比例与强度，而不是只保留“阳性/阴性”。
- 目前这些标志物多为关联证据；应与临床和影像变量联合、在独立样本中验证。

### 3. 遗传与表观遗传

- 胚系：检测适应证、基因面板、变异分类、遗传咨询状态。
- 体细胞：测序深度、肿瘤纯度、变异等位基因频率、拷贝数/全基因组 LOH、突变特征。
- 记录 GNAS、USP8 等亚型相关改变，以及选定侵袭性病例中的 TP53、ATRX、SF3B1 等候选变异；它们不能脱离亚型和治疗史解释。

最新遗传共识指出，体细胞检测在侵袭性/难治性病例的研究和特定临床情境中有价值；研究结果仍需与病理、影像和临床演变整合。 [Pituitary Society 遗传检测共识](https://www.nature.com/articles/s41574-026-01291-4)

### 4. 患者重要结局

- 生活质量量表、疲劳、睡眠、认知、工作能力、性功能及治疗负担。
- 视功能、内分泌功能和长期替代治疗不应只是协变量，也可以成为独立预测终点。

## C 层：发现与机制变量

### 1. 转录组、单细胞与空间组学

- bulk RNA：RNA 质量、建库、测序深度、批次、肿瘤纯度。
- 单细胞：组织处理时间、活率、双细胞率、细胞注释、批次与整合策略。
- 空间组学：切片区域、空间分辨率、肿瘤边缘/侵袭前沿、病理配准和细胞分割质量。
- 目标：识别肿瘤细胞状态、免疫/基质生态位、去分化和 EMT 等与侵袭及治疗反应相关的程序。

公开单细胞和空间研究已显示 PitNET 存在肿瘤、髓系细胞、淋巴细胞、成纤维细胞、内皮细胞等多种细胞群与空间重塑；这适合作为机制发现，而非直接临床分类。 [单细胞/空间研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12122724/)

### 2. 蛋白组与磷酸化组

- 样本前处理、冷缺血时间、蛋白提取、质谱平台、批次、缺失机制与归一化。
- 分析信号通路、受体状态、DNA 修复、细胞周期、代谢和治疗靶点；以与转录组、病理和疗效的交叉验证为准。

### 3. 代谢组与脂质组

- 采样类型（血、尿、组织）、空腹/采样时间、保存温度与时间、平台、内标、批次和药物状态。
- 优先提出“可复测的代谢状态/通路”假设，而不是在小样本中筛选大量单代谢物。

### 4. 液体活检

- 血清/血浆类型、采样时间、离心与保存、cfDNA/外泌体/循环标记物测定方法。
- 目前主要适合作为动态监测和研究探索；需前瞻性验证其增量价值。

2025 多组学综述指出，PitNET 的组学工作正在揭示信号、代谢和免疫相关分子亚群，但侵袭性、复发和疗效的稳健临床标志物仍然缺乏。 [多组学综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC12434087/)

## 必须并行收集的时间轴

每一类变量都需要以下锚点：

1. 首次症状/确诊；
2. 治疗前；
3. 手术与病理；
4. 首次术后 MRI；
5. 早期生化评估；
6. 每次药物/放疗/再手术；
7. 每次影像和激素随访；
8. 进展、复发、转移或最后无事件随访。

## 分析地图

| 分析模块 | 核心问题 | 建议方法 |
| --- | --- | --- |
| 描述性流行病学 | 不同亚型、治疗路径和结局如何分布？ | 队列流程图、缺失图、事件时间线、分层表 |
| 预后/复发 | 谁会出现进展或再治疗？ | 生存分析、竞争风险、动态预测；外部验证 |
| 治疗反应 | 哪些患者对药物或放疗获益？ | 纵向混合模型、目标试验模拟、异质性治疗效应 |
| 影像 | 侵袭与残留如何影响结局？ | 体积纵向模型、标准化分割、影像组学增益评价 |
| 病理与组学 | 何种生物学状态驱动侵袭/耐药？ | 亚型分层、批次校正、多组学因子整合、通路富集 |
| 微环境 | 免疫、基质和血管生态位如何关联进展？ | 单细胞/空间差异丰度、细胞互作和空间邻域分析 |
| 因果与公平性 | 治疗是否有效、模型是否可迁移？ | 混杂调整、敏感性分析、按中心/年代/亚型的校准与公平性 |

## 预测模型的正确顺序

1. 用 A 层变量建立透明的基线临床模型。
2. 在时间外和外部队列评价区分度、校准度与净获益。
3. 逐层加入 B 层变量，检验是否有可重复的增益。
4. 用 C 层变量做生物学分型、机制假设和候选靶点发现。
5. 只有在独立验证和临床影响评估后，才考虑使用于决策支持。

模型报告采用 TRIPOD+AI，偏倚与适用性审查采用 PROBAST+AI。 [TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378) [PROBAST+AI](https://www.bmj.com/content/388/bmj-2024-082505)

## 现阶段最值得优先回答的三个问题

1. 在同一病理谱系内，影像侵袭、术后残留和早期激素反应能否可靠预测 3 年进展？
2. 标准化病理和分子特征在临床模型之上是否带来可外部复现的增益？
3. 侵袭/耐药是否对应稳定、可靶向的细胞状态或微环境生态位？

## 数据与解释红线

- 不混合不同亚型、不同预测时点和不同结局定义来追求更大样本。
- 不用未来治疗、未来 MRI 或随访信息预测过去。
- 不将组学关联直接称为临床生物标志物。
- 不公开原始可识别患者数据、影像或遗传数据。
